# HWS Job Testing Guide

คู่มือทดสอบโมดูล Job (งานขนส่ง) ของระบบ HWS (Highways Shipping) — Laravel admin system ที่ D:\Workspace\hws-laravel

เปิดไฟล์ [`job-testing-guide.html`](./job-testing-guide.html) ในเบราว์เซอร์เพื่ออ่าน (มีเช็คลิสต์ที่จำความคืบหน้าไว้ในเบราว์เซอร์นั้นๆ)

เนื้อหาอ้างอิงจากโค้ดจริงใน `app/Http/Controllers` และ `routes/web.php` ณ วันที่ 2026-09-05 ครอบคลุม:
- ข้อมูลหลักที่ต้องเตรียมก่อนทดสอบ (master data)
- ขั้นตอนสร้าง Job และฟิลด์ทั้งหมด
- สายงานขั้นตอน (step pipeline) ของทิศทางนำเข้า/ส่งออก/ในประเทศ
- งานย่อยทั้ง 9 อย่างที่ทำได้จากหน้า Job (สั่งงาน Shipping, Messenger, จองรถ, ใบส่งของ, Shipment/ตู้, ใบขนสินค้า, เอกสารแนบ, เบิกเงิน, ปิดต้นทุน)
- ข้อควรระวัง/พฤติกรรมที่ตั้งใจให้เป็นแบบนั้น ไม่ใช่บั๊ก
